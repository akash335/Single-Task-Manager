Single Task Manager

A lightweight, single-user Task Manager you can use to create, edit, delete, and filter tasks—designed for speed and simplicity. Deployed on Vercel.

Live Demo: https://single-task-manager.vercel.app/

Features

✅ Add / edit / delete tasks

⏰ Optional due dates & reminders (client side)

🔎 Filter by status (All / Pending / In-Progress / Completed)

💾 Local persistence via localStorage (no backend required)

📱 Responsive UI (mobile → desktop)

⚡ Zero-config deploy on Vercel
